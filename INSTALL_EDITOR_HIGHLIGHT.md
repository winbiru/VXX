# V++ syntax highlighting

This project includes a local VS Code language extension for `.vi` and `.vvm` files.

## V++-style installer

This is the V++ installer for V++ language support. It does not require external package managers.

```bash
./scripts/vpp-lang install
```

Install the `vpp-lang` command into your user PATH:

```bash
./scripts/vpp-lang self-install
vpp-lang install
```

Install for one editor:

```bash
./scripts/vpp-lang install --editor vscode
./scripts/vpp-lang install --editor cursor
./scripts/vpp-lang install --editor vscodium
```

Other commands:

```bash
./scripts/vpp-lang list
./scripts/vpp-lang pack
./scripts/vpp-lang uninstall --editor vscode
./scripts/vpp-lang self-uninstall
```

The `pack` command creates a `.vlang` package in `dist/`.

## VS Code

After installing, reload VS Code and open any `.vi` file.

For development without installing:

1. Open this project in VS Code.
2. Press `F5`.
3. In the Extension Development Host window, open a `.vi` file.

## Other editors

Editors that support VS Code extension folders can use the files generated by `vpp-lang install`.

JetBrains IDEs, Vim, Neovim, and Sublime Text need their own syntax plugin/file format; they do not directly use this VS Code extension.
