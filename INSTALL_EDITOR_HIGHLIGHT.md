# VietVM syntax highlighting

This project includes a local VS Code language extension for `.vi` and `.vvm` files.

## VietVM-style installer

This is the VietVM installer for VietVM language support. It does not require external package managers.

```bash
./scripts/vietvm-lang install
```

Install the `vietvm-lang` command into your user PATH:

```bash
./scripts/vietvm-lang self-install
vietvm-lang install
```

Install for one editor:

```bash
./scripts/vietvm-lang install --editor vscode
./scripts/vietvm-lang install --editor cursor
./scripts/vietvm-lang install --editor vscodium
```

Other commands:

```bash
./scripts/vietvm-lang list
./scripts/vietvm-lang pack
./scripts/vietvm-lang uninstall --editor vscode
./scripts/vietvm-lang self-uninstall
```

The `pack` command creates a `.vlang` package in `dist/`.

## VS Code

After installing, reload VS Code and open any `.vi` file.

For development without installing:

1. Open this project in VS Code.
2. Press `F5`.
3. In the Extension Development Host window, open a `.vi` file.

## Other editors

Editors that support VS Code extension folders can use the files generated by `vietvm-lang install`.

JetBrains IDEs, Vim, Neovim, and Sublime Text need their own syntax plugin/file format; they do not directly use this VS Code extension.
