# Hóa đơn cửa hàng

Sample project V++ nhỏ nhưng có cấu trúc dự án thật: manifest schema 1, source tách module,
class có constructor, import tương đối và smoke test nghiệp vụ.

```bash
vpp dựng src/main.vi
vpp chạy src/main.vi
vpp kiểm thử tests
```

Với dữ liệu mẫu, chương trình in tổng thanh toán `125000`.
